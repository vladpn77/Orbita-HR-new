# Орбита — сайт кадрового агентства

Адаптивный статический сайт из 4 страниц (чистые HTML/CSS/JS), открывается на компьютере и телефоне.

## Структура

```
Orbita-HR-new-main/
├── index.html      — главная
├── about.html      — о компании, показатели, контакты, карта
├── catalog.html    — услуги (с фото) и вакансии с умными фильтрами
├── price.html      — прайс-лист с умными фильтрами
├── styles.css      — основные стили сайта
├── a11y.css        — версия для слабовидящих
├── print.css       — версия для печати
├── images/         — staff.jpg, specialists.jpg, executives.jpg
└── js/
    ├── main.js     — меню для телефона, кнопка «Версия для печати»
    ├── a11y.js     — панель для слабовидящих
    └── filters.js  — умные фильтры (вакансии и прайс)
```

## Возможности

- **Мобильное меню** — выпадает под кнопкой-«бургером», закрывается по клику вне меню, по Esc и при переходе по пункту.
- **Версия для печати** — кнопка в подвале и в панели для слабовидящих; также работает обычная печать браузера (Ctrl+P).
- **Версия для слабовидящих** — кнопка с глазом в шапке: размер текста, цветовые схемы, интервалы, шрифт Arial, отключение изображений. Настройки запоминаются.
- **Умные фильтры** — поиск с синонимами и защитой от опечаток, категории со счётчиками, город, формат, зарплата, сортировка. Выбранные фильтры сохраняются в адресе страницы.
